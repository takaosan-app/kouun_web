使い方

こんなときは

栽培の場面ごとに、アプリで何をすればよいかをまとめました。くわしい手順は、それぞれのページをご覧ください。

使い始めるとき

はじめて使うとき

アプリを入れて、アカウントを作り、1つ目の圃場を登録します。→ 初期設定

苗場と本圃を分けて育てるとき

苗場と本圃を、それぞれ別の圃場として登録しておきます。栽培を開始するときに、「使う圃場」で苗場と本圃を選ぶためです。本圃で育苗するときは、苗場と本圃に同じ圃場を選べます。施設区分（露地・雨よけ・ハウス）も、苗場と本圃のそれぞれに入れておきます。→ 圃場の一覧の「圃場を追加する」「施設区分」

1つの苗場で、2つの品種を別々に記録したいとき

1つの圃場で、同時に継続中にできる栽培は1つです。1つの苗場で2つの品種を育て、品種ごとに栽培の記録をつけるときは、苗場を品種の数だけ、別の圃場として登録してください（例：「藤枝の苗場（章姫）」「藤枝の苗場（紅ほっぺ）」）。

  • 位置は、同じ場所でかまいません。足元の状況や注意情報は、観測所の値で計算するので、観測所が同じなら、位置を少しずらしても変わりません
  • それぞれ独立した圃場になるので、ほかの圃場の記録には影響しません
  • 定植した後も品種ごとに記録するときは、本圃も同じように、品種の数だけ登録してください。同じ本圃に2つ目の栽培を定植すると、1つ目の栽培が栽培終了になります
  • 観測所と施設区分は、それぞれの圃場に入れます（同じものでかまいません）
  • 「栽培開始」で、品種ごとに栽培名を付け（例：2027年 章姫）、それぞれの苗場と本圃を選びます
  • 登録できる圃場の数には、上限があります（今は10件まで）

→ 圃場の一覧の「圃場を追加する」、栽培日誌の「使う圃場を選ぶ」

いちごの作期の流れ

栽培を始めるとき

「栽培日誌」の「栽培」のタブで「栽培開始」を押し、栽培を開始します。

  • 「作物」は「いちご」、「栽培方法」は「土耕」か「高設（棚）」を選びます
  • 「開始日」は、栽培を始めた日にします
  • 「栽培名」には「2027年 いちご」のように入ります。そのままでも、書き換えてもかまいません
  • 「使う圃場」で、苗場と本圃を選びます。それぞれの施設区分も確かめます

→ 栽培日誌の「栽培を開始する」

育苗を始めたとき

「記録」のタブで苗場を選び、「節目」の「育苗開始」に印を付けて保存します。

→ 栽培日誌の「節目を記録する」

苗を購入して植えるとき

栽培を開始するときに、「使う圃場」の苗場を「選択しない」にし、本圃だけを選びます。苗を植えたら、「記録」のタブで本圃を選び、「本圃へ定植」に印を付けて保存します。

本圃で前の栽培が継続中のときは、その本圃を選べません。先に、前の栽培に「栽培終了」を記録してください。

→ 栽培日誌の「使う圃場を選ぶ」

冷蔵処理を始めたとき・終えたとき

「記録」のタブで、その日の「節目」の「冷蔵処理開始」（終えたときは「冷蔵処理終了」）に印を付けて保存します。冷蔵処理の間は、栽培のカードに「冷蔵処理中」の印が出ます。

→ 栽培日誌の「節目を記録する」

本圃へ定植したとき

「記録」のタブで苗場を選び、「本圃へ定植」に印を付けます。栽培を開始したときに選んだ本圃が、自動で入ります。保存すると、栽培が本圃に移ります。

  • 本圃で前の栽培がまだ継続中のときは、確かめの窓が出ます。「栽培終了にして本圃へ定植する」を押すと、前の栽培を定植の日で栽培終了にしてから、定植を記録します
  • 花芽分化確認や開花開始を記録した後でも、まだ定植していなければ、本圃へ定植を記録できます

定植の後は、「足元の状況」で起点を定植の日にすると、定植からの積算を見られます。

→ 栽培日誌の「本圃へ定植する」、足元の状況の「期間を選ぶ」

花芽分化を確かめたとき

「記録」のタブで、「花芽分化確認」に印を付けて保存します。

花が咲き始めたとき

「記録」のタブで、「開花開始」に印を付けて保存します。

収穫が始まったとき・終わったとき

「記録」のタブで、「収穫開始」（終わったときは「収穫終了」）に印を付けて保存します。収穫終了を記録しても、栽培はまだ終わりません。片付けが済んだら、栽培終了を記録してください（下の「片付けが済んだとき」）。

片付けが済んだとき

「記録」のタブで、「栽培終了」に印を付けて保存します。確かめの窓が出たら、「栽培終了にする」を押します。栽培は、「栽培」のタブの「終わった栽培」に移り、その圃場で次の栽培を始められます。

収穫終了の日に片付けまで済んでいれば、収穫終了と栽培終了に一緒に印を付けられます。

→ 栽培日誌の「栽培を終える」

途中で栽培をやめたとき

「記録」のタブで、「栽培中止」に印を付けて保存します。栽培を削除すると記録がすべて消えるので、やめたときは削除せずに「栽培中止」を記録してください。

別の作物に替えたときは、「この栽培を修正する」で作物を変え、「作物を替えた」を選ぶこともできます。前の栽培は「栽培中止」として残ります。→ 栽培日誌の「作物を変える」

ふだんの記録

雨が降った日

「記録」のタブの「天気」で「雨」を選びます。地面が濡れる程度以上に降ったときに選んでください。

作業をした日

「記録」のタブの「作業」で、した作業を押します。いくつでも選べます。

病気や虫を見つけたとき

「記録」のタブの「病害虫を記録する」を押し、「害虫」か「病害」を選んで、名前とメモを入れます。名前がわからなくても記録できます。

→ 栽培日誌の「病害虫を記録する」

前の記録を見返したいとき

「履歴」のタブで圃場を選ぶと、直近2年の日誌・節目・病害虫の記録が、日付の降順に1日1行で並びます。行を押すと、「記録」のタブでその日の記録が開きます。

栽培ごとに見るときは、「栽培」のタブで栽培を押すと、その栽培の節目と病害虫の記録が並びます。

→ 栽培日誌の「履歴を見る」「栽培の一覧と経過を見る」

困ったとき

節目を入れ忘れたとき

「記録」のタブで、日付を「日付を変える」でその日にし、節目に印を付けて保存します。今の段階より前の節目は、「前の段階の節目（入れ忘れたときに）」を開くと選べます。

節目の日付を間違えたとき

「栽培」のタブで栽培を押し、経過の中の節目を押すと、日付を直せます。間違えて記録したときは「取消にする」を押します。栽培開始の日付は、ここでは直せません（下の「栽培の開始日や栽培名、使う圃場を間違えたとき」）。

→ 栽培日誌の「節目を直す・取り消す」

栽培の開始日や栽培名、使う圃場を間違えたとき

「栽培」のタブで栽培を押し、経過の画面の右上の「…」から「この栽培を修正する」を押します。開始日、栽培名、栽培方法、作物名、使う圃場、施設区分を直せます。開始日は、次の節目の日より将来の日付には変更できません。

→ 栽培日誌の「栽培を修正する」

作物を選び間違えたとき

「この栽培を修正する」で作物を変えて保存し、「打ち間違いを直す」を選びます。前の栽培は、記録ごと削除されます。

栽培を開始したこと自体が誤りのときは、「この栽培を削除する」で削除します。節目と病害虫の記録も、すべて消えます。

→ 栽培日誌の「作物を変える」「栽培を削除する」

栽培の途中で別の圃場へ植え替えたとき

苗場から本圃への定植のほかに、栽培の途中で別の圃場へ植え替えたときは、使う圃場を変えずに、今の栽培を「栽培中止」にして、新しい栽培を開始してください。「この栽培を修正する」で使う圃場を変えるのは、登録の誤りを直すときだけです。

→ 栽培日誌の「栽培を修正する」

雨よけやハウスを建てたとき

「圃場の一覧」で、圃場のカードの「…」から「圃場の情報を変える」を押し、施設区分を変えます。栽培を開始するときや、本圃へ定植するときにも変えられます。→ 圃場の一覧の「施設区分」

今年の暑さや雨を、昨年や平年と比べたいとき

「足元の状況」で、指標と期間を選びます。今年・昨年・平年の積算が、グラフと表で出ます。→ 足元の状況

観測所を変えたいとき

「圃場の一覧」で、圃場のカードの「…」から「気温の観測所を変える」（または降水量・日照）を押します。→ 圃場の一覧の「観測所を変える」

パスワードやニックネームを変えたいとき

「会員情報」で、パスワード（またはニックネーム）の右の「変更する」を押します。→ 会員情報の「パスワードを変更する」「ニックネームを変更する」

パスワードを忘れたとき

「ログイン」の画面の「パスワードを忘れた方」から、メールに届くコードで再設定します。→ 会員情報の「パスワードを忘れたとき」

使うのをやめたいとき

「会員情報」の「退会する」で退会できます。すべてのデータが消え、元に戻せません。→ 会員情報の「退会する」

アプリでできないこと

アプリの決まりで、できないことをまとめました。代わりにできることがあれば、「代わりに」に書いています。

圃場

  • 圃場の位置を変える
  • 代わりに：新しい圃場として追加してください。→ 圃場の一覧の「圃場の位置は変えられません」
  • 削除した圃場を元に戻す。削除した圃場に日誌を書く
  • 代わりに：もう一度、圃場を登録してください。→ 圃場の一覧の「圃場を削除する」
  • 上限（今は10件）を超えて、圃場を登録する
  • 代わりに：使っていない圃場を削除してください。→ 圃場の一覧
  • 1つの圃場で、2つの栽培を同時に継続中にする（ほかの栽培が今いる圃場を苗場にして、栽培を開始することもできません）
  • 代わりに：品種ごとに、圃場を分けて登録してください。位置は同じでかまいません。→ 上の「1つの苗場で、2つの品種を別々に記録したいとき」
  • 同じ本圃に、2つ目の栽培を定植する（先に継続中であった栽培は、確かめのうえ、定植の日で栽培終了になります）
  • 代わりに：本圃も、品種ごとに分けて登録してください

栽培

  • いちご・その他のほかの作物（水稲、果樹など）を、作物として選ぶ
  • 代わりに：「その他」を選び、作物名を入れてください。→ 栽培日誌の「その他の作物」
  • 栽培の作物を、そのまま別の作物に変える
  • 代わりに：「この栽培を修正する」で作物を変えると、「打ち間違いを直す」か「作物を替えた」を選ぶ窓が出ます。どちらも、前の栽培を削除するか栽培中止にして、新しい栽培を登録します。→ 栽培日誌の「作物を変える」
  • 栽培開始を取消にする
  • 代わりに：栽培を削除して、開始し直してください。節目と病害虫の記録も消えます。→ 栽培日誌の「栽培を削除する」
  • 栽培の開始日を、次の節目より将来の日付に変える
  • 代わりに：先に、次の節目の日付を直してください
  • 終わった栽培を、「この栽培を修正する」で直す
  • 代わりに：栽培終了・栽培中止を取消にして、継続中に戻してから直してください。取消が断られるときは、下の「節目の記録と取消」を見てください。節目の日付とメモは、終わった栽培でも直せます
  • 栽培が今いる圃場を、ほかの栽培が継続中の圃場に変える（「この栽培を修正する」の使う圃場）
  • 代わりに：別の圃場を選ぶか、その圃場の栽培を、先に栽培終了にしてください
  • 栽培の途中で別の圃場へ植え替えたことを、使う圃場の変更で記録する
  • 代わりに：今の栽培を栽培中止にして、新しい栽培を開始してください。→ 上の「栽培の途中で別の圃場へ植え替えたとき」

節目の記録と取消

  • 将来の日付で、日誌や節目を記録する
  • 代わりに：その日になってから記録してください
  • 栽培開始の日より過去の日付で、節目を記録する。節目の日付を、栽培開始の日より過去に直す
  • 代わりに：先に、「この栽培を修正する」で開始日を直してください
  • 栽培終了・栽培中止の後に、節目を記録する
  • 代わりに：栽培終了・栽培中止を取消にして、継続中に戻してから記録してください
  • 栽培終了・栽培中止の日付を、最後の節目より過去にする
  • 代わりに：先に、最後の節目の日付を直してください
  • 終わった栽培で、節目の日付を、終えた日（栽培終了・栽培中止の日）より将来の日付に直す
  • 代わりに：先に、栽培終了・栽培中止の日付を直してください
  • 節目を直す窓で、節目の圃場を変える
  • 代わりに：「この栽培を修正する」で、使う圃場を直してください
  • 取消にした節目を、元に戻す
  • 代わりに：同じ節目を、記録のタブで記録し直してください
  • 取消や日付の直しで、1つの圃場に継続中の栽培が2つになる。次の2つの場合です
  • 前の栽培の栽培終了・栽培中止を取消にして継続中に戻すとき、その圃場で、後の栽培がもう継続中である
  • 本圃へ定植の取消や日付の直しで栽培が前の圃場に戻るとき、そこで、ほかの栽培が継続中である
  • 代わりに：窓に出る栽培の節目を先に直して、圃場を空けてください。例：前の栽培の栽培終了を取消にしたいときは、後の栽培の本圃へ定植を先に取消にします
  • 削除した圃場に栽培が戻る取消
  • 代わりに：ありません。圃場の削除は元に戻せないので、削除する前に確かめてください

記録を見る・写真

  • 履歴のタブで、2年より過去の記録を見る
  • 履歴のタブは、直近2年の記録を並べます。栽培ごとの記録は、栽培のタブで、その栽培の経過を見てください
  • 写真を登録する
  • 次の版で対応する予定です

注意情報

  • その他の作物で、作物ごとの注意情報を受け取る
  • 理由：作物ごとの注意情報は、病害虫が出やすい天気の条件を、作物ごとに調べて用意するものです。今は、いちごの分だけを用意しています
  • 作物共通の知らせは、その他の作物の圃場にも出ます。ただし、作物共通の知らせの今の対象は、果樹カメムシ類だけです（作物共通の灰色かび病は準備中です）。このため、実際に知らせが出るのは、春以降になる見込みです
  • 代わりに：足元の状況で、気温と雨の積算を見てください。→ 足元の状況
  • いちごでも、次のときは知らせが出ません
  • 施設区分が空の圃場。炭疽病・灰色かび病・アザミウマ類のどれも出ません。→ 圃場の一覧の「施設区分」
  • 炭疽病：育苗開始を記録していない栽培（苗を購入して植えた栽培など）。また、育苗の間（苗場で育苗するときは本圃へ定植の前の日まで、本圃で育苗するときは開花開始の前の日まで）に、露地・雨よけにいるときだけ出ます
  • 灰色かび病・アザミウマ類：ハウスだけで、開花開始（記録していなければ収穫開始）から収穫終了までです。開花開始も収穫開始も記録していなければ出ません。アザミウマ類は、1年に1回だけです
  • 収穫終了の日より将来（片付けの間）と、栽培終了・栽培中止の日より将来
  • 天気の条件がそろわないとき
  • 苗場で育苗する栽培で、本圃へ定植を記録しないままにすると、炭疽病の知らせが出続けます
  • 定植を記録するまで、育苗の間として計算するためです。定植したら、節目を記録してください
  • 節目や施設区分を記録したり直したりしたとき、知らせに反映されるのは、次の計算のときです
  • 知らせは、屋外の観測所の値による参考情報です。ハウスの中の様子や、病害虫が実際に出ているかは分かりません
