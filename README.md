## 1. 最初に守ること

### 返答の言語

- 返答、説明、コミットメッセージはすべて日本語で書く。英語の返答は誤解の原因になる
- コマンド、ファイル名、コードの識別子など、英語でしか書けないものだけはそのまま使う
- アプリの画面の文言も日本語とする

### 進め方（開発者の強い希望）

- ファイルやフォルダの作成、コーディングは、AIが作成した案をベースに開発者が行う。
- 開発の計画・進捗に管理に関するMDファイルの更新はAIが行うが、必ず事前に内容を開発者に確認する。
- まず全体像を把握し開発者と共有する。
- 大きな流れを示してから、方針と手順を開発者に確認する。細部から入らない
- その次に、必要なファイルとコードの案を示す。細かくステップを刻んで進める
- コードの案の提示に際しては、クラスの概要やコードの意味等の解説を簡潔に入れる
- 複数の選択肢がある場合は、長所と短所を示して開発者に判断を委ねる
- 「一気に」「お願いします」と言われても、元に戻せない操作（データの削除、DBの変更、
  公開・送信）は直前に確認する
- この依頼は時間がたつと忘れがちなので、何度も思い出すこと
